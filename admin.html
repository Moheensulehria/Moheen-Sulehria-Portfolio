Manage your portfolio.

Edit your public details and publish the content file to your GitHub Pages repository. Changes appear on the live site after GitHub Pages rebuilds.

Important security note

This static admin page is not a server-secured login. For live publishing it asks you to paste a short-lived/limited GitHub token when you publish; the token is used in memory only and is not saved in this page or browser storage. Use a fine-grained token limited to this one repository with Contents: Read and write. Anyone who gets that token may edit your repository. Never paste a token into the website source or commit it.

Use this to commit data/site-content.json to your GitHub repository. It does not change HTML/CSS files. Make sure GitHub Pages is already enabled for the same repository.

How to create the token safely
  1. Open GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Choose only your portfolio repository.
  3. Grant Contents: Read and write. Do not grant administration or workflow permissions.
  4. Generate the token, paste it above only for publishing, then clear the field after use. Consider revoking the token after publishing if you do not need it again.

LIMITATIONS & NEXT STEPS

What this admin page can do

  • Edit profile details and the featured SDLC project description.
  • Download a JSON backup for versioning or manual upload.
  • Commit the content JSON through the GitHub API so the deployed site can load updated values.
  • It does not upload profile photos or replace the résumé PDF yet; replace those files in the repository and commit them normally.

For a production-grade multi-user CMS with proper authentication, use a dedicated CMS/OAuth backend. GitHub Pages itself does not provide private server-side admin authentication.
